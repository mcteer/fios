# Private qualification and serving contract

All names below describe proposed additions. Retain the existing OS-peer operator socket, enrolled worker mTLS framing and same-origin browser bridge. No raw paths, model-supplied commands or network destinations enter a request.

| Caller | Request and authority | Observable result |
| --- | --- | --- |
| Local admin · probe approval | Import immutable candidate/adapter metadata, frozen suite, allowed probe file digests and byte ceilings. Check Mini rehearsal, current 005 hardware basis, Studio identity, reviewed probe mapping and fresh per-host budgets. | Authorize transfer of the named probe files only and a bounded two-rank probe. Record a stage-specific refusal for missing metadata, unsafe sizing or inadequate resources. |
| Local admin · full-pack approval | Reference that probe's actual two matching successful receipts and per-host cleanup. Recheck identities, candidate/adapter, reviewed full partition and replicated/transient peak estimates, each host's current disk space and memory floor. | Authorize the restricted downloader to stage only the exact full pack. Reject probe-only approval, stale capacity, failed/mismatched probe or missing cleanup before any full shard transfer. Verify actual files, keys and shapes after download before native load. Record estimated single-host fit separately from the pair-only placement rule. |
| Local admin | Submit a reviewed case via the existing incarnation and idempotency-key envelope against the real reservation ledger. | Duplicate intent returns the original job. Conflicting intent, old incarnation, unenrolled or substituted slot, downgraded capability or invalid basis cannot start a rank. A busy pair waits holding neither slot. |

No substituted model. Only reporter output that passes current publication policy and joint settlement becomes visible, with one usage entry. |

**Operational measurements.** Take the idle host swap-used baseline immediately before the run under both reservations. Observe headroom, swap-used, pressure and per-rank physical footprint at least once per second and at phase transitions. A sample gap over two seconds or missing endpoint fails the attempt. End the load phase after both verified partitions are ready. End prefill when the first token is produced. Observe decode until last output or cancellation. Compare swap in integer bytes, allow equality to the 32 GiB floor, and immediately abort on pressure above normal, swap growth or headroom below floor. Host swap growth from unrelated activity also invalidates the run. Never sum overlapping memory counters. Apply safety guards to live use as well as trials.

**Review and trust.** Receipts carry bounded summaries and references instead of private prompts. Bind failures to their expected reason and clean holds, including when a disconnected rank must reconcile later. The trusted Core can attest to a job outcome and review status. It cannot manufacture a missing hardware measurement. Keep raw fixture review, chat history and operational metadata separate.
