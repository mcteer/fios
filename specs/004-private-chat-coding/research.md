## Serving, publication and retention

Build fixed requests from a fios alias. MLX-LM's upstream HTTP surface allows extra fields such as model paths and adapters. Use offline preverified local weights, private native runtime access and a typed browser interface. A closed HTTP stream alone gives insufficient evidence of native cleanup. Probe cessation, terminate the owned executor if necessary, and reacquire fresh capacity. [Upstream HTTP interface](https://raw.githubusercontent.com/ml-explore/mlx-lm/main/mlx_lm/SERVER.md)

Evaluate an offline text-policy checker for prompt, answer and title. Qwen3Guard-Stream is a candidate with incremental feedback, tokenizer-specific input, broad categories and custom code requiring review. Its generic categories do not encode fios's distinction between permitted adult fantasy and prohibited sexual depictions of minors. Gate the exact detector, policy mapping and withholding behavior against boundary fixtures. Measure its footprint and false denials. Support full-answer review for sensitive context and hold ambiguous material. A mock verdict proves the boundary plumbing only. [Publisher's guard model card](https://huggingface.co/Qwen/Qwen3Guard-Stream-0.6B)

Keep ordinary chat history in owner-scoped private storage on the Mini. Generate short titles locally from approved content. Starting with deterministic topic extraction avoids a second model load or an unaccounted generation. Compare the results to a subject rubric on held-out topics. Projects and cross-chat retrieval have their own roadmap milestone.

## Integration evidence from the checkout

The dashboard uses a serial HTTP server, a read-only observation mount and GET-only authorization. The enrollment process owns the private operator socket. Existing jobs accept synthetic profiles, enforce a two-Studio slot constraint, use a synthetic tariff and quarantine both slots after restore. Worker frames are sized for control messages. Give browser traffic a narrow chat capability and bounded concurrent handling, and extend the native job service with versioned storage, per-slot reconciliation and grant-scoped content transfer. Keep existing synthetic interfaces and acceptance tests.
