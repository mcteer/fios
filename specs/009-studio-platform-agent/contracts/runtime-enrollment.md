# Runtime construction boundary — source implementation

`RuntimeEnrolledPolicy.load` constructs fixed runtime adapters only for the kernel-identified installed manager at `/Library/Application Support/Fios/Studio/bin/studio-manager`. Development, fixture and PR images return no policy before reading installation metadata. There is no task/operator JSON operation, environment override, alternate policy file, injectable file reader or public policy initializer.

The fixed policy is `/Library/Application Support/Fios/Studio/runtime-enrollment.json`. It must pass the existing descriptor-based root-owned/no-symlink/no-ACL/size/mode/stability reader. Its exact version1 schema contains `purpose: reviewed_platform_runtime`, positive nonroot `uid`, one of the two approved Studio `host` identities, canonical `state_path`, a direct `/Users/ACCOUNT` `home_path`, and lowercase SHA256 `review_sha256`, `manager_sha256`, `docker_sha256`, `orbctl_sha256`. Duplicate/unknown/coerced/oversized fields refuse. UID, host and state must match the executing manager. The account home must be a real directory owned by that UID with no group/other write mode. The review hash names the operator's review receipt; neither it nor the decoded document is whole-repository/native provenance, source coverage or task admission proof.

The manager and Docker program must be reviewed root-owned, single-link immutable installation files. The Docker program has the fixed path `/Library/Application Support/Fios/Studio/bin/docker`, preserving its multicall basename without following the installed mutable Docker alias. Staging that binary, its dependency/provenance review and serialized stopped upgrades remain installer work; this factory does not copy or install it. Native OrbStack metadata uses the fixed `/Applications/OrbStack.app/Contents/MacOS/scli.app/Contents/MacOS/scli` path and independently pinned bytes. The complete OrbStack application tree must pass the bounded immutable-tree check before construction, so bundled dependencies/resources are not accepted from a writable tree. The factory checks current manager kernel PID/start/path and the reviewed current on-disk executable hashes; it does not attest mapped code or reconstruct dependency provenance. Immutable-path lifetime across later invocation still requires the reviewed installation and serialized upgrade discipline.

Docker uses only `--host unix://` plus the reviewed account home's fixed `/.orbstack/run/docker.sock` suffix. Neither inherited HOME nor Docker contexts select it. VM inventory/cap readers also receive that explicit reviewed home. This is not a complete socket-directory/ACL lifetime check or daemon peer attestation; those execution-boundary checks remain required before wiring. same-user host compromise remains outside the sandbox isolation claim. Generic command execution rejects environment keys except a canonical absolute HOME and exact `DOCKER_CONFIG=/var/empty`, `DOCKER_CLI_HINTS=false`; child PATH and locale are fixed, with no inherited credentials, context or dynamic-library overrides. Fixed typed callers retain the existing two process slots, probe/action deadlines, identity-checked signals, finite output and exact-child reap/retention policy. CLI timeout remains unavailable/uncertain, never native terminality or proven non-dispatch.

Construction performs no native CLI, daemon, container, application or model operation. The public manager composition still does not enable this runtime executor. Native compatibility/absence, authoritative activity/admission, approved images, resource/lease/ownership and installed acceptance must be completed independently before execution can be wired. No policy or executable was installed by the source fixtures. T009 integration and T049/T051 remain open; parser/development-refusal tests are not installed acceptance.
