# Original-root non-dispatch reconciliation

This contract resolves only `(job,attempt)` as `not_sent`. It does not prove device
completion, host idle, all-client coverage, native compatibility or new admission.
It never clears another inference record or refunds request history.

The local input is an opaque producer value: either the factory's once-only
never-spawned result carrying the original handoff, or the fixed private worker's
validated terminal/zero-POST summary after exact kernel absence and durable reap.
A census, signal, HTTP result, counter or local service acknowledgement alone
cannot construct that input. The worker contract requires metadata2, pipe1 and
native_handoff1; its sole possible model POST binds the original native instance,
correlation and full-width root. Public/enrollment gates remain independent.

The native input is a fresh authenticated cancellation of that same original,
previously checkpointed root. The native tracker cancels only an unconsumed
registration before any model binding. Late fixed-root HTTP cannot fall back to
ordinary association. Handed-off, unknown, mismatched, stale or replayed replies
cannot close the claim; a handed-off contradiction permanently fences that
consumer. The original kernel peer/image/start, native epoch, correlation, root,
capture clock and monotonic sequence must match. No absent root becomes proof.

The manager retains at most32 subjects and issues one off-loop cancellation at a
time. Results survive journal contention without resending the native RPC.
Failed/invalidated reconciliation retains native uncertainty. Independently
accepted terminal decisions are preserved. Neither cleanup nor rollback infers
native terminality from this local process lifecycle.

An accepted decision atomically persists its original lineage/decision receipt,
deletes only its own unresolved inference row and sets only its scope to
`not_sent`. Request history remains spent. Version2 lineage checkpoints bind the
local producer, metadata/handoff versions, launch nonce and (for reaped workers)
stored grant hash to the original native peer/root/cancellation sequence. Startup
requires the matching durable reaped launch and producer rows. Older version1
checkpoints remain readable; older readers reject version2. Rollback uses the
retained old artifact's original compatible stopped backup, never a downgrade of
new state. Backups/restores preserve the accepted decision and unrelated holds.

Validation distinguishes synthetic pre-admission/no-model fixtures from real
native evidence. The empty-catalog native workflow combines actual factory
no-spawn evidence with actual authenticated root cancellation, retains an older
uncertain claim across restart and denies a late cancelled-root POST. The actual
installed child/mock workflow verifies the separate reaped-zero-POST branch.
Neither workflow grants production enrollment, activation or native admission.
Positive model completion and all-client quiescence remain unfinished.
