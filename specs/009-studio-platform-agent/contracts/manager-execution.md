# Manager execution composition — source implementation

The serialized `ManagerRuntime` loop now accepts an internal `ManagerExecutionPorts` value. The public entry still supplies none: it uses no worker factory, runtime executor, approved images, model binding or native capacity issuer. No CLI/environment/IPC schema constructs ports or selects their callbacks. Installed/root-policy/native compatibility and admission enrollment remain unfinished and independently gated.

Ports supply the reviewed runtime/image set, optional installed Python factory, bounded cached resource source and model-binding/admission snapshots. Construction accepts at most eight immutable image IDs; sandbox images require a runtime, and an image-free configuration requires a worker factory. It creates no runtime object or worker. Effects still use the existing asynchronous two-slot executor/broker, durable journal, resource reservations and proof-gated cleanup. The enrolled runtime's endpoint policy reaches both metadata and attach consumers.

VM source selection is explicit: `unavailable` discards supplied VM bytes, `cached` consumes an already validated coherent external cache, and `ownedContainer` uses the controller's verified envelope reader. A missing configured resource snapshot yields unknown memory/CPU/disk/pressure/thermal/VM fields rather than falling back to a different sensor. Admission independently checks freshness, headroom, quotas and retained commitments. This callback interface does not validate physical/native provenance or mint a VM coverage permission; a production cache/enrollment issuer still must do so. Snapshot callbacks must only read bounded caches, never run CLI/network/database/model work on the heartbeat loop.

Worker polling and sandbox model frames are keyed by job ID, while current-source lookup is keyed by canonical model. The manager resolves the immutable owned broker/sandbox scope before looking up the current model source; a job UUID is never treated as a model name. Broker scope identities compare raw UTF-8 bytes, including canonical/native model IDs, rather than Swift canonical Unicode equality.

The binding source receives the actual running manager epoch. The manager independently rejects a different epoch, invalid model identity or byte-different canonical model, even if a cache returns it. Source metadata cannot select the manager's generation. Native capacity and admission remain false by default, and a binding is not an atomic native admission reservation. T002/T020/T022 and production model execution remain unfinished.

Task upload completion rechecks admission before consuming input or registering execution. Admission loss revokes the upload/job through the existing cancellation path; later end replay is status-only. It does not clear native uncertainty or treat an attempted operation as proven absent. Resource removal and optional completion/output receipts may become visible on adjacent coordinator turns: clients must require the receipt appropriate to their claim, not infer successful code execution from `removed` alone.

Validation commands:

- `node scripts/check-platform-manager-execution.mjs --mock` compiles a dedicated temporary fixture and drives real manager processes/task IPC for public-disabled, admission-closed and missing-resource cases. It uses `/usr/bin/false` as a never-needed runtime stand-in, performs no daemon call and is included in the macOS CI lane.
- `node scripts/check-platform-manager-execution.mjs --isolated` uses the existing local immutable `fios:current` image, builds a uniquely labelled runner image with no pull/network, and exercises one configured512MiB/1CPU sandbox through real manager IPC, chunk upload, execution, owner output, verified removal and full manager restart without replay. It verifies an unrelated sentinel survives. Host/VM samples are explicitly synthetic; no native source, model binding, worker or inference is enabled. This is local OrbStack fixture evidence, not enrolled sensor/native acceptance or the full pressure/outage/cleanup matrix.
- Adding `--models` to either manager-execution command drives the installed private Pydantic worker against the finite fake loopback/Unix native endpoint. Docker-free CI covers a stale manager-epoch cache (zero workers/POSTs), unknown exact model refusal, one complete model-only POST and consumed-input replay without another POST. Local isolated mode additionally runs a model-mediated sandbox through manager IPC, one additional fake POST, explicit artifact/output frames, worker reap and verified owned-container removal. It never uses an installed serving model and is not model competence/native acceptance.
- `node scripts/check-platform.mjs --mock --mutate-manager-epoch` removes only the epoch equality check in a private source copy. It must fail the actual `Stale manager generation binding accepted` assertion, not a compiler/linker error. Normal Debug/optimized suites use the genuine source.

The isolated fixture never opens its live manager's journal in another process. Success closes/reaps each manager before restart, verifies exact task-object absence, removes only its saved full-ID/name/image/owner sentinel and uniquely labelled image, then removes its generated directory. Failure stops/reaps owned managers and preserves state/resources with a bounded identity receipt; recovery must independently verify actual saved identities/absence and must not clear inference ownership or delete unrelated resources. No production SQLite, service restart, installed policy, host settings, LAN/RDMA or legacy volume is selected.

Model-enabled fixture bootstrap is a single≤4KiB parent-only stdin packet to a separately compiled temporary fixture entry. A finite off-loop reader accepts only the generated private observation socket, loopback ephemeral HTTP endpoint and canonical manager UUID, then publishes an in-memory cache. Snapshot callbacks perform no bootstrap I/O. The production manager has no such stdin protocol or runtime/model argument override. The fake server uses the existing private-worker fixture schema; it does not establish the final normalized native all-client source.
