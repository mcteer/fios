This is an administrative bypass-client experiment, not a Fios interface path or platform job. It constructs no fixture admission grant. Ordinary interface inference remains under the private Pydantic harness. A prepared capsule/plan confers no installation, runtime-management or native admission authority.

The current fixed case is local `mlx-community/gemma-4-e4b-it-4bit`, backend `gemma4`, in `~/.mlx-serve/models/mlx-community/gemma-4-e4b-it-4bit`. ## Prepare without inference

The full native fixture accepts an optional `--review-output /ABS/PRIVATE_PARENT/NEW_CAPSULE`, following its optional MIMO pair. The parent must already be private and owned by the unprivileged operator. This still runs the ordinary15-root/empty-model HTTP/control/manager checks, with no model input.

The new private capsule contains the source executable and seven runtime/data files. Only its copies receive private relative rpaths/install names and development ad-hoc signatures. Every Mach-O code/data section digest must remain unchanged. System dependencies and the fixed colocated runtime set are checked; installed/source input libraries are preserved. Failed copies remain diagnostic data. A completed receipt binds all artifact bytes, original binary hash and declared source/runtime/MIMO inputs. It is not whole-history/native provenance, an approved release or an installer input.

```sh
node scripts/check-platform-native-model.mjs --plan --capsule /ABS/CAPSULE --sha256 REVIEWED_CAPSULE_RECEIPT_SHA --output /ABS/PRIVATE_PARENT/NEW_PLAN.json
node scripts/check-platform-native-model.mjs --check --plan /ABS/PLAN.json --sha256 REVIEWED_PLAN_SHA
```

Planning fingerprints the existing model files, runner inputs, profile and a readonly kernel observer. It does not start a model. The check starts only a private source process with an **empty** model directory, asserts zero advertised models/zero model POSTs and reaps its exact PID/start identity. It cannot request inference. The plan remains unconsumed.

```sh

```

The plan is consumed durably before spawning. Its exact runner/profile/observer/capsule/model bytes must still match. Synthetic observations are refused in run mode. No retry or second POST is allowed.

The case uses one authenticated loopback-only private source instance, one selected model, context512, concurrency1 and at most8 output tokens. The12GiB resident/physical-footprint value is an abort threshold sampled every500ms (including the first sample), not a hard GPU/physical-memory quota. The observer must match the original kernel PID/start/UID before signaling; unknown identity remains retained/reported, never signaled by PID alone.

A kernel profile permits only the private listener/control endpoints, denies outbound network access, fork and other execs, and permits filesystem writes only within the child's private home. Model files, capsule and parent-held records remain read-only to the child. Parent receipts and one-use intent are fsynced separately. The source server gets a fresh strict API key through its private environment, never gateway/Studio credentials. Raw diagnostics, generated text and reasoning are not logged. Failed HTTP responses retain only status, fixed diagnostic categories and a message SHA; known source error templates can be compared by hash without retaining server prose. No installed application, launchd, Docker, RDMA or legacy data operation occurs.

A zero sampled phase count does not prove that phase absent; missed short phases remain unobserved. These are partial request-ownership phases, not GPU execution or terminal evidence.

The receipt reports source coverage `unknown` and native quiescence `unproven`. A successful response is partial source/backend acceptance, not model competence, all-client admission or T051 completion. Reaping never clears independent inference uncertainty.
