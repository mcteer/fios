# Specification quality checklist

Review against [spec.md](../spec.md) on 2026-11-27.

- [x] Each story names its actor, value, priority and independent acceptance test.
- [x] Observable outcomes distinguish placement, publication, cleanup and promotion.
- [x] Success criteria cover both ranks, actual transport, a matched baseline and refusal paths.
- [x] Concurrency, missing evidence, failure, denial, privacy and recovery have acceptance cases.
- [x] Constraints, dependencies and future roadmap boundaries are explicit.
- [x] Hardware claims require subsequent measurements. Planning makes no performance claim.
- [x] An unpublished candidate has an admin-only trial path with shared exclusive holds, bounded fixtures and separate promotion.
- [x] Each adapter has generation-bound positive observations and a TCP-only negative control using one verifier.
- [x] The large MoE fit trial follows comparable-model validation and has per-Studio headroom and workload criteria in the roadmap.
