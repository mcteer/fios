# ADR0003: Narrow Studio platform management authority

Date:2026-10-26. Status: accepted for implementation by the user's renewed instruction to proceed after the specific amendment and read-only SSH scope were presented. Not approval for deployment, privilege escalation, model workloads or a native server integration change.

## Decision and rationale

Constitution2.1.0 permits only009's unprivileged native Studio supervisor/manager/session adapter, short-lived private Pydantic workers and finite network-isolated temporary agent sandboxes. A manager inside OrbStack cannot recover OrbStack while it is unavailable. Native all-client observation is needed to unblock008 without pretending managed-only request ledgers prove idle.

Privileged/runtime policy stays deterministic. Sandboxes receive no host mount/namespace, socket, credential, privilege or external network. Model-generated text grants no permissions. Native manifests/artifacts are reviewed and versioned; installation is explicit, with stopped-state backup/rollback. Existing app-only automatic delivery does not install native code.
